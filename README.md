# Трекер расходов ExpenseTracker

Трекер расходов позволяет с помощью Telegram бота записывать расходы (траты) в базу данных

## Технологии:
- C#
- .NET 10
- SQL Server
- Entity Framework Core + миграции
- Telegram.Bot
- User Secrets
- Git

## Что умеет эта программа
- Добавлять расходы
- Показывать список расходов
- Удалять расходы
- Редактировать расходы

## Структура проекта
|Проект|Назначение|
|------|----------|
|ExpenseTracker|Консольное приложение (первая версия трекера)|
|ExpenseTracker.Core|Общая библиотека с моделью данных `Expense`|
|ExpenseTracker.Api|Web API с CRUD-операциями и доступом к базе данных|
|ExpenseTracker.Bot|Telegram-бот, работающий с API|

## Модель данных
Расход (класс `Expense`):
- Id - уникальный идентификатор
- Amount - сумма одного расхода (decimal)
- Category - категория
- Date - дата расхода

## Возможности приложения
### Telegram-бот
- Принимает сообщения в формате `категория сумма` (например, `кофе 500`)
- Разбирает сообщение и проверяет корректность ввода
- Отправляет расход в Web API, который сохраняет его в базу данных
- Подтверждает пользователю результат работы с расходом

**Полная цепочка:** *Telegram -> бот -> Web API -> база данных*

### Web API
|Метод|Endpoint|Действие|
|------|------------|---------------|
|GET|`/expenses`|Получить список всех расходов|
|POST|`/expenses`|Добавить новый расход|
|DELETE|`/expenses/{id}`|Удалить расход по его Id|
|PUT|`/expenses/{id}`|Редактировать расход по его Id|

## Статус проекта
Проект в активной разработке 

## Планы по развитию

**Категории:**
- Готовый шаблон базовых категорий (например: продукты, бытовая химия, транспорт и т.д.)
- Возможность пользователя создавать свой список категорий
- Добавление, редактирование и удаление категорий
- Создание отдельной таблицы категорий в базе данных

**Работа с расходами:**
- Добавление нового поля "Описание": *что именно* куплено (например, категория "Продукты", описание "Кофе")
- Ввод нескольких расходов одним сообщением (через запятую и с новой строчки)
- Редактирование и удаление конкретных записей в конкретных категориях
- Обработка ошибок построчно: корректные записи сохраняются, а ошибочные бот просит перезаписать

**Telegram-бот:**
- Кнопки для выбора категорий и действий с ними
- Приветствие пользователя по имени
- Привязка расходов и категорий к конкретному пользователю

**Отчеты:**
- Отчет по всем категориям
- Отчет по одной выбранной категории
- Итоговая сумма расходов за указанный период
